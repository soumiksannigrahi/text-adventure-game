# Text-Based Adventure Game 🎮

## Overview
A console-based adventure game built in Java where players navigate through rooms using commands.

## Features
- Command-based navigation (go, take, drop, look)
- Inventory system
- Room-based exploration
- File-based game data (Rooms, Items, Score)
- Scoring system

## Tech Stack
- Core Java
- OOP (Object-Oriented Programming)
- Java Collections (HashMap, ArrayList)
- File Handling (BufferedReader)

## How to Run

```bash
javac -d bin src/adventure/*.java
java -cp bin adventure.Main
